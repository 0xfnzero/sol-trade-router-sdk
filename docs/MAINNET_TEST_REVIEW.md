## CPMM exact-output capacity follow-up

The existing inverse quote test reproduced a valid-output rejection: base reserve `u64::MAX / 2`, quote reserve 1,000,000, no fees, requested output 400,000. The original search doubled its initial estimate beyond token vault capacity, swallowed that error as zero output, and eventually returned overflow despite a valid smaller input. The search now bounds gross input by the net mint-fee credit that fits the input vault, checks whether the target is reachable, propagates quote/configuration errors, and uses checked narrowing for the fee-free lower bound.
